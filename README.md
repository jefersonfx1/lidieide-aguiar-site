# Site - Psicóloga Lidieide Aguiar

Site profissional da **Psicóloga Lidieide Aguiar** (CRP 01/31063).

## Sobre

- Especialidade: ansiedade, neuropsicologia, acolhimento emocional
- Público: adolescentes e adultos
- Atendimento: 100% online
- Design inspirado em landing pages de clínicas modernas (estilo Valyos)

## Funcionalidades

- Botões **Agendar agora** com link direto para WhatsApp
- Formulário de agendamento que envia dados via WhatsApp
- Área preparada para integração com **Google Calendar**
- Front-end de **checkout** pronto para conectar gateway de pagamento (Stripe, Mercado Pago, PagSeguro etc.)
- Design responsivo e acolhedor
